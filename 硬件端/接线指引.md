# 硬件端接线指引

Orange Pi 4 Pro + 面包板 + 传感器。**全程不需要焊接。**

> ⚠️ **接线前必读**：接错 5V 会烧板子。**一次只接一个元件，验通了再接下一个。**

---

## 一、先看这张引脚分配表

依据官方 40-pin 对照表挑的引脚（都避开了固定功能占用）：

| 物理脚 | 芯片 | 全局号 | 用途 |
|:---:|:---:|:---:|---|
| 29 | PD0 | **96** | 1 号仓 LED |
| 31 | PD1 | **97** | 2 号仓 LED |
| 33 | PD2 | **98** | 3 号仓 LED |
| 35 | PD3 | **99** | 4 号仓 LED |
| 37 | PD4 | **100** | 5 号仓 LED |
| 38 | PD7 | **103** | 6 号仓 LED |
| 12 | PL8 | **360** | 1 号仓 霍尔 |
| 13 | PL12 | **364** | 2 号仓 霍尔 |
| 15 | PK24 | **344** | 3 号仓 霍尔 |
| 16 | PL5 | **357** | 4 号仓 霍尔 |
| 18 | PK25 | **345** | 5 号仓 霍尔 |
| 22 | PD23 | **119** | 6 号仓 霍尔 |
| 24 | PE12 | **140** | 蜂鸣器 |
| 40 | PL13 | **365** | 确认按键 |

**电源与地**（40-pin 上）：

```
3.3V → 脚 1、17
5V   → 脚 2、4
GND  → 脚 6、9、14、20、25、30、34、39
```

> `config.py` 里填的是**全局号**（右列），不是物理脚号。

---

## 二、三个必须记住的电气参数

| | |
|---|---|
| **GPIO 是 3.3V 逻辑** | 输出高电平 3.3V，**不能直接接 5V 器件** |
| **单脚驱动电流很小** | 约 8~20mA。**LED 必须串限流电阻**，蜂鸣器必须走模块 |
| **板子要 5V/3A 供电** | 摄像头 + 风扇 + 传感器一起上，供电不够会莫名重启 |

---

## 三、分步接线（每步都要验）

### 第 0 步：先确认 GPIO 能读能写

**什么都不接**，先跑：

```bash
cd ~/smart-pillbox/硬件端
python3 main.py --selftest
```

**第 3 项 GPIO 要是 ✓。** 不是的话先解决它，别往下走。

---

### 第 1 步：接一个 LED（只接一个！）

```
Orange Pi          面包板
  脚 29 ────────→ 150Ω 电阻 ──→ LED 长脚（正极）
  脚 6  ────────→ LED 短脚（负极）
                   （脚 6 是 GND）
```

**LED 长脚是正极**，接反了不亮（但不会烧）。

**验证**：

```bash
python3 tools/test_gpio.py blink 96
```

**✓ 闪烁** → 引脚对，接线对，往下走。
**✗ 不亮** → 见下面排查表。

---

### 第 2 步：把剩下的 LED 接上

照第 1 步的样子，接到 97、98、99、100、103，GND 共用。

**验证**：

```bash
python3 tools/test_gpio.py scan
```

会依次点亮每个引脚，**盯着药盒看亮的顺序对不对**。顺序不对就调 `config.py` 里 `LED_PINS` 的顺序。

---

### 第 3 步：接蜂鸣器

买的是**有源蜂鸣器模块**（3 针：VCC / GND / IN）：

```
Orange Pi          蜂鸣器模块
  脚 24 ────────→ IN
  脚 2  ────────→ VCC   （脚 2 是 5V）
  脚 9  ────────→ GND
```

> ⚠️ **必须用模块版**。散装两脚蜂鸣器工作电流 20~30mA，GPIO 推不动，直接接会烧引脚。

**验证**：

```bash
python3 -c "
from hal import OrangePiHardware
import time
hw = OrangePiHardware()
for _ in range(3):
    hw.beep(300); time.sleep(0.3)
hw.cleanup()
"
```

**✓ 响三声** → 成了。

---

### 第 4 步：接霍尔传感器（先接一个）

A3144E 是**三脚**（字面朝自己，从左到右）：VCC / GND / OUT

```
Orange Pi                    A3144E
  脚 2 (5V) ─────────────→ VCC
  脚 14 (GND) ───────────→ GND
                             OUT ──┬──→ 脚 12
                                   │
                          10kΩ 上拉电阻
                                   │
                              脚 17 (3.3V)
```

**三个关键点**：

1. **VCC 必须接 5V**（A3144E 最低工作电压 4.5V，3.3V 不工作）
2. **OUT 必须串 10kΩ 上拉到 3.3V** —— A3144E 是开漏输出，没有上拉读不出高电平
3. **不能把上拉接到 5V** —— 那会输出 5V 打到 3.3V 的 GPIO 上

**验证**：

```bash
python3 tools/test_gpio.py watch 360
```

拿磁铁靠近/离开霍尔，看读数变化：

```
[15:32:01] 电平 高  → 判定为「合盖」
[15:32:05] 电平 低  → 判定为「开盖」     ← 磁铁靠近时
```

**✓ 读数会变** → 引脚对了。
**✗ 一直不变** → 把磁铁**翻面试试** —— A3144E 是单极霍尔，只对特定磁极响应。

---

### 第 5 步：接按键

```
Orange Pi          按键
  脚 40 ────────→ 一端
  脚 20 ────────→ 另一端  （脚 20 是 GND）
```

按键**不需要外部上拉** —— 代码里开了内部上拉。

**验证**：

```bash
python3 -c "
from hal import OrangePiHardware
import time
hw = OrangePiHardware()
print('按 5 秒内按下按键…')
for _ in range(100):
    if hw.is_button_pressed():
        print('✓ 读到按键'); break
    time.sleep(0.05)
else:
    print('✗ 5 秒内没读到按键')
hw.cleanup()
"
```

---

### 第 6 步：接完剩下的霍尔

照第 4 步，接到 364、344、357、345、119。

**验证**：

```bash
python3 main.py
# 按 0~5 模拟开盖，看流程对不对
```

## 四、出错了怎么排查

| 现象 | 可能原因 | 怎么办 |
|---|---|---|
| **LED 完全不亮** | 正负极接反 | 把 LED 转 180° |
| | 没串电阻 | 补上 150Ω |
| | 引脚号填错 | `test_gpio.py blink <号>` 换一个试 |
| | 引脚被复用占用 | 换表里另一个纯 GPIO 脚 |
| **LED 很暗** | 电阻太大 | 换成 150Ω |
| | 用了蓝/白 LED | **换红黄绿** —— 蓝白压降 3.2V 太接近 3.3V |
| **蜂鸣器不响** | 买成无源的了 | **必须是有源**。无源的要 PWM 驱动 |
| | 接成散装两脚款 | 必须用**模块版**（带三极管驱动） |
| **霍尔读数不变** | VCC 接了 3.3V | **必须接 5V** |
| | 没接上拉电阻 | OUT 串 10kΩ 到 3.3V |
| | 磁铁极性不对 | **翻面试试** |
| **按键一直显示按下** | 引脚没接对 | 换一个引脚 |
| **板子莫名重启** | 供电不足 | 换 5V/**3A** 以上的适配器 |
| **所有 GPIO 都失败** | 权限不足 | 用 `sudo` 跑，或把用户加进 gpio 组 |

**还有问题就把完整输出发我。**

## 六、安全红线

```
❌ 不要把任何 GPIO 直接接到 5V
❌ 不要用 GPIO 直接驱动电机/继电器/大功率 LED
❌ 不要在通电状态下插拔杜邦线
❌ 不要一次把 14 个引脚全接上再测试

✅ 一次一个，验通了再下一个
✅ 接之前先用万用表确认电压
✅ 不确定就先问
```
